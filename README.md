# ARISE

**Awakening & Respiratory Integration for Safe Extubation**

An evidence-based clinical decision support tool for ICU liberation protocols.

![ARISE Screenshot](https://via.placeholder.com/800x400?text=ARISE+Screenshot)

## Overview

ARISE helps ICU teams standardize and optimize the extubation process through:

- **SAT Screening** — Spontaneous Awakening Trial eligibility assessment
- **SBT Screening** — Spontaneous Breathing Trial readiness evaluation  
- **Full Pre-Extubation Assessment** — Comprehensive extubation planning with risk stratification

## Features

✓ Evidence-based thresholds with citations  
✓ Auto-calculation of P/F ratio, BMI  
✓ Risk stratification for post-extubation support  
✓ Mobile-friendly responsive design  
✓ Works offline (single HTML file)

## Evidence Base

All clinical thresholds are supported by peer-reviewed research including:
- ATS/CHEST Guidelines 2017
- PADIS Guidelines 2018
- Multiple systematic reviews and meta-analyses
